# Serviço Despertar

A função de wake-up call usa por defeito o prompt clássico `this-is-yr-wakeup-call`.

Na imagem do add-on é tentada a instalação da gravação portuguesa em `pt_BR/this-is-yr-wakeup-call`; quando não estiver disponível, o runtime cai automaticamente para a gravação inglesa `this-is-yr-wakeup-call` e, em último recurso, para `beep`.

O GUI mostra qual destas gravações está realmente disponível e permite testar a chamada de despertar imediatamente.
